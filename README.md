# KitKat Icons

A KitKat-style icon pack for Android. Original-looking KitKat icons for system apps, plus matching KitKat-style icons for popular apps like WhatsApp, Instagram, Spotify, Snapchat and more.

Tested on Nothing Launcher (Android 16).

## Install
1. Go to **Releases** and download the latest APK.
2. Install it (allow installs from your browser if Android asks).
3. Open your launcher settings and pick **KitKat Icons** as the icon pack.

## Missing an icon?
Open the app and tap **Share app list**, then open an issue and paste the list. I'll add the missing icons.
